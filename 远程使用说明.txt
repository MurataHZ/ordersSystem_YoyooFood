Yoyoo Food Station — Windows 10 远程使用说明

适用：台式电脑在家里/其他地点，两台 iPhone 在摊位使用流量或其他 Wi-Fi。
电脑和手机均需要上网，但不用在同一个网络。电脑可以插网线，不需要无线网卡。

已经运行过的服务器：本次更新步骤（保留现有记录）

1. 暂停接单，在现有服务器黑窗口按 Ctrl+C，等服务停止。
2. 复制现有项目里的整个 data 文件夹，放到其他位置留作备份。
3. 解压新版压缩包。从新版 boba-orders 文件夹中复制：
   - index.html
   - server.py
   - timezones 整个文件夹
   粘贴进目前正在用的 boba-orders 文件夹，选择替换同名文件。
   data 和 runtime 文件夹继续使用原来的，不要删除、改名或移走。
   这次不需要重新安装 Python 或 cloudflared。
4. 在原项目目录双击 start-remote-windows.cmd。
5. 等待生成新链接，两台 iPhone 使用新的完整链接打开页面。
6. 检查原来的数量、金额和待制作订单仍在，再测试新选项。

本次新增

- 前端珍珠可选 None，不加珍珠；后端和销售页显示“无珍珠”。
- 销售信息的已归档订单数量下方增加“详细历史”，可查看每次归档的日期、订单数量、订单总金额。
- 日期取永久归档前当前已完成列表第一笔订单的下单日期，按新西兰时间计算。
- 每次永久归档单独留一条日志；同日多次归档不合并。
- 金额仍按小杯 $6、大杯 $7 计入，单价仍显示 $5.99/$6.99。
- 旧版没有保存每次永久归档的日期，旧累计数会显示为“升级前归档／日期未知”，数量和金额保留；新日志从更新后开始。

首次使用前准备

1. 保留这份“Yoyoo_Food_Station_远程启动包.zip”。
2. 确保明早能在台式电脑上下载它。
   最直接的方法是在那台电脑的浏览器登录同一个 ChatGPT 账号，打开本对话下载。
   也可以自己先存到能在明早电脑上下载的私人网盘。无需 USB。
3. 确保台式机明早能正常上网，知道 Windows 的解锁密码。
4. 预留至少 30 分钟：第一次需要联网下载运行组件，并用两台 iPhone 试一单。

明早步骤

1. 打开台式电脑，接通电源和网络。浏览器能正常打开网页。
2. 下载远程启动包，右键压缩包，选择“全部提取/解压”。
   放到固定目录，例如 桌面\Yoyoo。不要在压缩包内直接双击启动文件。
3. 打开解压后的 boba-orders 文件夹，双击 start-remote-windows.cmd。
   这是远程版入口。原来的 start-windows.cmd 仍是局域网入口。
4. 首次启动自动从 Python 官方网站下载便携运行包，并从 Cloudflare 官方 GitHub 发布页下载 cloudflared。
   不需要手动安装 Python，不需要 VS Code、Java、Node.js、数据库软件、路由器端口映射或 Cloudflare 账号。
   下载耗时取决于网络。看到 [1/3]、[2/3]、[3/3] 是正常准备过程。
5. 等待出现“远程连接已建立”，窗口会打印完整的 https://...trycloudflare.com/s/.../ 地址。
   启动器也会尝试自动用电脑浏览器打开该地址。
   地址中 /s/ 后面是随机访问码，必须完整保留；不要只复制 trycloudflare.com 前面的域名。
6. 从电脑浏览器地址栏复制完整地址，发送到自己的手机，再分享给另一位操作员。
   两台 iPhone 都在 Safari 中打开同一个完整链接，一台进入前端，一台进入后端。
   这个链接相当于入场钥匙，只分享给负责操作的人。没有额外登录步骤。
7. 出门前，用手机关闭 Wi-Fi、使用流量做一次实际测试：
   - 创建一笔小杯、一笔大杯，确认制作端能看到。
   - 查看单价仍为 $5.99 / $6.99。
   - 完成两笔后，销售总额应为 $13.00。
   - 再试撤销、确认制作端恢复；再完成这一单，确认总额回到 $13.00，并刷新一次页面。
8. 此时两笔测试订单均应已完成，在销售页分别二次确认删除。当前数量和金额应变为 0，且撤销按钮没有可撤销的测试单。
   不要将测试单永久归档，否则会计入累计营业金额。
   删除测试单不重置订单编号。如果希望编号从 001 开始：仅在尚无正式营业记录时，停止服务，
   把测试用 data 文件夹改名为 data-test-backup，再重新启动，取得新链接。
9. 保持电脑联网，黑色启动窗口不要关闭。可以最小化、锁屏或关闭显示器，不要关机或手动休眠。
   启动器运行期间会尝试阻止自动睡眠，但不能阻止断电、Windows 重启或人为休眠。

营业结束

1. 回到电脑，在启动窗口按 Ctrl+C 停止，或者正常关闭服务。
2. 服务器停止后，备份整个 data 文件夹。订单和统计保存在其中。
3. 下次从同一文件夹启动，订单记录保留；手机需要换用这次新生成的链接。

常见问题

“为什么手机地址不是 192.168...？”
远程版使用 https://...trycloudflare.com/s/.../；192.168... 只适用于局域网。

“远程连接已建立，但页面暂时打不开？”
先等片刻，域名首次建立可能需要一点时间；确认完整地址没有漏掉 /s/ 后面的访问码。
再检查电脑和手机的网络，重新打开 Safari。不要重复新建同一杯。

“卡在下载或显示准备失败？”
保留错误信息，确认电脑能正常访问 python.org 和 github.com。
从同一文件夹重新运行会复用已下载完成的组件。
如果 GitHub 无法下载，可自己从下方 Cloudflare 官方下载页选 Windows 64-bit executable，
将文件改名为 cloudflared.exe，放到项目的 runtime 文件夹，再重试。
32 位 Intel/AMD Windows 电脑应选 32-bit executable。
Python 下载/校验失败请截图错误信息，不要从来路不明的网站下载替代文件。

“窗口说 8080 端口被占用？”
先关闭以前启动的订单服务器窗口，不要同时启动局域网版和远程版，再重试。

“链接过期或重新启动电脑后不能用了？”
重新双击 start-remote-windows.cmd，等生成新链接。两台手机都更新为新链接。
订单记录仍保存在 data 中。

“能否只开手机、把台式电脑关掉？”
不行。电脑实际保存订单并处理同步，整个营业期间需要开机联网。

“能否只留后台不用登录 Windows？”
本包是用户登录后手动启动的程序。锁屏可以；注销用户、重启或关闭窗口会停止服务。

“为什么只是临时地址？”
当前使用 Cloudflare Quick Tunnel。它免费、无需账号或域名，但官方将其定位为开发测试用途，
不提供在线率保证，且每次启动地址会变化。此包便于先试通和短期临时使用。
若要以后长期依赖它营业，需要再配置固定隧道或正式托管。
